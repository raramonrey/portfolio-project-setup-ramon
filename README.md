# portfolio-project-setup-ramon
Tools Installed
* **Cursor IDE:** A specialized AI code editor.
* **Claude Code Add-on:** AI assistant extension for Cursor.
* **Codex Add-on:** Documentation and AI-assisted workflow tool.
* **Git/GitHub:** For version control and project hosting.

## Steps Completed
1.  **Environment Preparation:** Downloaded and installed the Cursor IDE from the official website.
2.  **Extension Integration:** Accessed the Cursor marketplace to locate and install both Claude Code and Codex.
3.  **Authentication:** Successfully logged into all AI tools to ensure API connectivity.
4.  **Repository Setup:** Initialized this public repository on GitHub and cloned it locally to my machine using Cursor.
5.  **Documentation:** Synthesized the setup process into this README file.

## Challenges & Solutions
* **Challenge:** Initially, I couldn't find the "Codex" add-on because multiple extensions had similar names.
* **Solution:** I cross-referenced the requirements and looked for the version with the highest ratings/official branding to ensure I had the correct tool.
* **Challenge:** Configuring the GitHub connection within a new IDE.
* **Solution:** I used the Cursor command palette (Ctrl+Shift+P) and searched for "Git: Clone" to streamline the process.
* **Challenge:** Encountered a CommandNotFoundException when attempting to use Git commands in the terminal (Git was not recognized as a program).
* **Solution:** Identified that Git was not installed on the local system. Downloaded and installed Git for Windows, restarted the IDE to update the system PATH, and successfully verified the installation by re-running the configuration commands.
